# No Incognito

A small Chrome extension that automatically closes incognito windows as soon as Chrome tells it they have opened. No account, tracking, browsing-history access, or runtime dependencies.

**An extension cannot disable incognito itself.** The menu item and shortcut remain, a window can flash briefly, and navigation may start before the window closes. You must enable **Allow in incognito**. For actual browser-level prevention, use [Chrome's administrator policy](docs/disable-incognito.md).

## Install in desktop Chrome

1. Download this repository using **Code → Download ZIP**, then extract it.
2. Open `chrome://extensions` in a regular Chrome window.
3. Enable **Developer mode**, click **Load unpacked**, and select the `extension` folder containing `manifest.json`.
4. Save any work in existing incognito windows: enabling the next setting will close them.
5. On the No Incognito card, click **Details**, then turn on **Allow in incognito**.
6. Chrome may close the setup tab when this permission changes. Click the extension icon to reopen it (pin it from Chrome's Extensions menu if needed). It should say **Automatic closing is on**.
7. Try opening an incognito window. It should close automatically; regular windows should remain open.

If using `dist/no-incognito-1.0.0.zip` generated by the packaging command, extract it and load that extracted folder instead. This is an unpacked extension, not a Chrome Web Store installation. Keep its folder on disk.

## Behavior and limits

- Closes incognito windows, including private popup windows, without reading tab URLs or page content.
- Checks existing windows on installation, browser startup, worker startup, and status checks.
- Shows `ON` when incognito access is enabled and the window check succeeds; `!` means setup or attention is required.
- Status refreshes when opened, focused, or checked manually. No permanent background polling.
- Turning off incognito access, disabling/removing the extension, or using another Chrome profile, Guest mode, or another browser bypasses it. This is a personal browsing aid, not tamper-resistant enforcement.
- Already open incognito windows are closed when access is granted. Unsaved private-session work can be lost.
- Desktop Chrome only; Chrome on Android/iOS does not support this unpacked desktop extension.

## Privacy

The extension sends no network requests and stores no data. It does not request `tabs`, host, history, storage, or management permissions. Chrome's windows API supplies window IDs and the incognito flag without browsing-history permission. The policy guide link opens Google's website only when clicked.

## Development

Load `extension/` directly; no build step is needed. Use Node.js 22+ for tests and Python 3 for packaging.

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run package
```

The browser smoke test uses a temporary Chromium profile, enables incognito access in that profile, and checks window closing and permission revocation. It never changes your everyday Chrome profile. Screenshots go into `test-results/`. CI runs both test suites and publishes the installable ZIP as a workflow artifact.

For manual testing, also open incognito through the menu, keyboard shortcut, and a link's **Open link in incognito window** action; confirm that a regular window stays open. Reload the extension and restart Chrome to check recovery. Disable incognito access and confirm the popup returns to **Setup required**.
